# EIGHT PHARMACY — 지점 프로필 페이지

인스타그램 프로필 링크용 지점 안내 페이지와 그 관리자 페이지입니다.

| 파일 | 역할 |
|---|---|
| `index.html` / `style.css` / `script.js` | 공개 페이지 (손님이 보는 화면) |
| `admin.html` / `admin.css` / `admin.js` | 관리자 페이지 |
| `data.js` | 지원 언어, 화면 문구, 지점 **기본값** |
| `store.js` | Firestore 읽기/쓰기 |

- 공개 주소: `https://8pharmacy.kr/profile/`
- 관리자 주소: `https://8pharmacy.kr/profile/admin.html`

---

## 1. 처음 한 번만 하는 설정

Firebase 프로젝트: **`pharmacy-productlist`** (콘솔 표시 이름 `8pharmacy-productlist`)
아래 세 가지만 콘솔에서 켜주시면 됩니다.

### (1) 관리자 계정 만들기

Firebase 콘솔 → **Authentication** → 로그인 방법 → **이메일/비밀번호** 사용 설정 →
Users 탭에서 관리자 계정을 하나 추가합니다. (예: `admin@8pharmacy.kr`)

> 비밀번호는 Firebase가 직접 보관합니다. 이 코드 어디에도 비밀번호는 저장되지 않습니다.

### (2) 승인된 도메인 등록

Authentication → Settings → **승인된 도메인**에 아래를 추가합니다.

```
8pharmacy.kr
localhost          (Live Server로 테스트할 때 필요)
127.0.0.1
```

### (3) Firestore 보안 규칙

Firestore → 규칙에 아래 블록을 **추가**합니다.
(기존 규칙을 지우지 마시고, `match /databases/{database}/documents { ... }` 안쪽에 넣으세요.)

```
match /profile/{docId} {
  allow read: if true;                    // 지점 정보는 누구나 볼 수 있어야 함
  allow write: if request.auth != null;   // 저장은 로그인한 관리자만
}
```

### (4) 첫 저장

`admin.html` 에 로그인하면 "아직 Firestore에 저장된 내용이 없습니다"라는 안내가 뜹니다.
내용을 확인하고 **[저장]** 을 한 번 누르면 `profile/config` 문서가 만들어지고, 그때부터
공개 페이지가 Firestore 값을 읽습니다.

## 2. 관리자 페이지에서 할 수 있는 것

**지점**
- 추가 / 삭제 / 순서 이동(↑ ↓)
- 지점 코드, 지역, 도시 태그, 전화번호, 사진 URL
- 영업시간을 **평일 / 토요일 / 일요일** 세 가지로 각각 설정 (요일별 휴무 체크 가능)
- 심야 영업 표시
- 지도 링크 4종: **네이버지도 · 카카오맵 · 구글맵 · 고덕지도(高德, 중국)**
- 지점 전용 인스타그램 / 틱톡 (있을 때만)
- 지점명 · 한 줄 태그 · 주소 · 설명을 **9개 언어**로 각각 입력

**지역** — 상단 필터에 나오는 묶음입니다. 추가하면 필터에 자동으로 나타납니다.

**공식 채널** — 전 지점 공통 인스타그램 / 틱톡.

**백업** — 편집 중인 내용을 JSON으로 내려받고, 되돌릴 때 다시 불러올 수 있습니다.

> 비워둔 링크의 버튼은 손님 화면에 아예 나타나지 않습니다.
> 예를 들어 고덕지도 링크가 없는 지점은 고덕지도 버튼이 보이지 않습니다.

| `id` | Indonesia | `flag-id.png` |

- 처음 방문하면 **브라우저 언어로 자동 선택**되고, 한 번 고르면 그 브라우저에 기억됩니다.
- 어떤 언어의 내용을 비워두면 그 자리는 **영어 → 한국어** 순으로 대신 표시됩니다.
  화면이 비어 보이는 일은 없습니다.
- 언어를 더 늘리려면 `data.js` 의 `LANGS` 배열에 한 줄 추가하고, `UI` 에 같은 코드의
  문구 묶음을 추가하면 됩니다. 관리자 페이지의 언어 탭도 자동으로 늘어납니다.

## 4. 알아두실 점

- **Firestore가 안 열려도 페이지는 정상 표시됩니다.** 인터넷이 끊기거나 규칙이 잘못돼도
  `data.js` 의 기본값으로 그려지고, 콘솔에만 경고가 남습니다.
- 영업중 / 곧 마감 / 영업 종료 표시는 **한국 시간 기준**으로 계산합니다.
  외국에서 접속해도 한국 시간으로 정확히 나옵니다.
- 사진을 넣지 않은 지점은 초록 배너에 큰 `8` 이 들어간 기본 이미지로 표시됩니다.
